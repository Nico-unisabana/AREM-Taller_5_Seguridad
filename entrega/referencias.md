## 📚 Referencias utilizadas

### Metodología de modelado de amenazas
1. Shostack, A. *Threat Modeling: Designing for Security*. Wiley, 2014. ISBN 978-1-118-80999-0.
2. Microsoft. "Microsoft Threat Modeling Tool – STRIDE threats". [Enlace](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool-threats).
3. OWASP Foundation. *Threat Modeling Cheat Sheet*. [Enlace](https://cheatsheetseries.owasp.org/cheatsheets/Threat_Modeling_Cheat_Sheet.html).
4. OWASP Foundation. *OWASP Juice Shop*. [Enlace](https://owasp.org/www-project-juice-shop/).
5. OWASP Foundation. *OWASP Top 10:2021* (A01 Broken Access Control, A03 Injection). [Enlace](https://owasp.org/Top10/).

### Normativa colombiana
6. Congreso de Colombia. *Ley Estatutaria 1581 de 2012*, por la cual se dictan disposiciones generales para la protección de datos personales. [Enlace](https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=49981).
7. Presidencia de la República. *Decreto 1377 de 2013*, compilado en el Decreto Único Reglamentario 1074 de 2015. [Enlace](https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=53646).
8. Congreso de Colombia. *Ley 527 de 1999*, mensajes de datos, comercio electrónico y firmas digitales. [Enlace](https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=4276).
9. Congreso de Colombia. *Ley 1273 de 2009*, protección de la información y de los datos (delitos informáticos). [Enlace](https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=34492).
10. Superintendencia de Industria y Comercio. *Guía para la implementación del principio de responsabilidad demostrada (Accountability)*. [Enlace](https://www.sic.gov.co/).

### Sector financiero y asegurador
11. Superintendencia Financiera de Colombia. *Circular Externa 007 de 2018*: requerimientos mínimos para la gestión del riesgo de ciberseguridad (Circular Básica Jurídica, Parte I, Título IV, Capítulo V). [Enlace](https://www.superfinanciera.gov.co/).
12. Superintendencia Financiera de Colombia. *Circular Externa 005 de 2019*: uso de servicios de computación en la nube. [Enlace](https://www.superfinanciera.gov.co/).

### Estándares y marcos de buenas prácticas
13. ISO/IEC. *ISO/IEC 27001:2022 — Information security management systems — Requirements*. [Enlace](https://www.iso.org/standard/27001).
14. ISO/IEC. *ISO/IEC 27002:2022 — Information security controls*. [Enlace](https://www.iso.org/standard/75652.html).
15. NIST. *The NIST Cybersecurity Framework (CSF) 2.0*. NIST CSWP 29, 2024. [DOI](https://doi.org/10.6028/NIST.CSWP.29).
16. NIST. *SP 800-218: Secure Software Development Framework (SSDF) v1.1*. 2022. [DOI](https://doi.org/10.6028/NIST.SP.800-218).
17. OpenSSF. *SLSA — Supply-chain Levels for Software Artifacts*. [Enlace](https://slsa.dev/).
18. Center for Internet Security. *CIS Critical Security Controls v8*. [Enlace](https://www.cisecurity.org/controls/v8).
19. Microsoft. *Microsoft Cloud Security Benchmark*. [Enlace](https://learn.microsoft.com/en-us/security/benchmark/azure/overview).
20. Microsoft. "Dynamic data masking – Azure SQL Database". [Enlace](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview).
21. Microsoft. "Azure Bastion" y "Just-in-time VM access (Defender for Cloud)". [Enlace](https://learn.microsoft.com/en-us/azure/bastion/bastion-overview).
22. Microsoft. "Phishing-resistant authentication methods in Microsoft Entra ID". [Enlace](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-authentication-strengths).
23. GitHub. "About SAML single sign-on for organizations" y "About protected branches". [Enlace](https://docs.github.com/en/organizations).
24. Atlassian. "Manage user access and product licenses in Jira Cloud". [Enlace](https://support.atlassian.com/).
